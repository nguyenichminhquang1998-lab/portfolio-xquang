# Archive

Thư mục này chứa handoff, phản biện và snapshot từ các vòng cũ.

- Chỉ dùng để hiểu lịch sử hoặc truy lại lý do thảo luận.
- Không coi nội dung ở đây là yêu cầu hiện hành.
- Khi có mâu thuẫn, dùng `AGENTS.md`, các quyết định `Accepted` trong `docs/DECISIONS.md` và tài liệu hiện tại ở `docs/`.
- Không sửa tài liệu lịch sử để làm chúng khớp với code mới.
